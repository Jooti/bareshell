## Visual identity

The original [BareShell logo source](assets/bareshell-logo.svg) is a terminal
chevron and cursor enclosed by a minimal shell silhouette. Android legacy,
adaptive, and monochrome themed icons use the same geometry. The product name
is **BareShell**; the Android identity is **net.jooti.bareshell**.
